# AGENTS.md — vibrantgio/.github

This repository is the plan root. No library code lives here.

## Do this

From this directory:

    mdplan next PLAN.md

That is the context packet: the standing rules, the phase and goal, and
the one unchecked task. Do that task's steps and nothing else. Check each
step off as you finish it:

    mdplan toggle -s "<task heading>" --item "<substring of the step text>" PLAN.md

`PLAN.md` is the authority for developing Vibrant Gio. Do not restate its
rules here. If a count, version, or tag in the plan is wrong, measure the
siblings and correct the plan with `mdedit` (name `PLAN.md` explicitly).

Work happens in the sibling clones beside this repo. Their parent is the
workspace root: `go.work` lives there, generated by `scripts/clone-all.sh`,
committed nowhere. Scripts in `scripts/` run from this directory when a
task in `PLAN.md` says so.

## Not this

`workbench/llms.txt` is the guide for writing an *application* against the
libraries. It is not how you work this plan.
